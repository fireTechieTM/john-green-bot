# AI Reward Finder on 2D Grid
I made this project so that I could experiment with changes to an "ai agent"'s environment. I now know there are highly efficient graph and/or dynamic programming algorithms that accomplish this same thing flawlessly and without the need for thousands of trials, but this project still serves its purpose as an example of how reinforcement learning models essentially work. The development of this project also forced me to interact with techniques I had not formally been aware of such as Manhattan distance.
